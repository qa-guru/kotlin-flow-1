# Диплом

### Задача:
- Создать новый проект с нуля
- Применить архитектуру PageObject и, если нравится, Chain
- Добавить подключение к Database через файл-конфигов
- Покрыть автотестами создание пользователя (UI) - не больше 5-и тестов
- Покрыть автотестами заведение товара (Backend) - не больше 5-и тестов
- Покрыть автотестами создание заказа (UI + Backend) - не больше 5-и тестов
- Написать параметризованый тест для измненеия статуса заказа и сделать проверки через UI и BACK
- Написать тест что пользователь создался в Database (UI + Backend + DB)
- Сделать удаление мусорных пользователей и заведенных заказов после тестирования (Backend)
- Написать парочку базовых тестов чисто на проверку массива или "калькулятор"
- Написать базовый тест на поиск Google c использованием SELENOID и RemoteDriver

### Бонус:
- Подружить тесты с Jenkins и чтобы можно было запускать только опредленные группы тестов из разных веток - как раз ту что содержит "базовые тесты"

### NB:
Не забываем расставлять Step / DisplayName / Tags / и прочее. 

### Минимальные требования:
- Все задания должны быть выполнены
- Тесты могут быть немного корявыми не идеальными, но должны работать и быть написаны в рамках архитектуры PageObject
- Использование всех пройденых фич включая Обьекты / TestListener / Allure и т.д.

### Максимальные требования:
- Все задания выполнены и работают стабильно
- Тесты написаны с соблюдением всех лучших практик и архитектуры PageObject
- Использование всех пройденых фич включая Обьекты / TestListener / Allure и т.д. с правильным применением и структурой
- Подружить тесты с Jenkins и возможность запускать только определенные группы тестов из разных веток
